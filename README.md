# CityBiz: Галерея — бизнес от первого лица в огромном ТЦ (Unity 6.6)

Мультиплеерный бизнес-симулятор **от первого лица** внутри торгово-развлекательного центра «Галерея». Вы ходите по ТЦ, арендуете или покупаете помещения, открываете магазины и кафе, нанимаете персонал и **улучшаете свои предприятия** — интерьер, оборудование, ассортимент, витрину/рекламу и охрану. Каждое улучшение видно глазами прямо в помещении. Конкуренты — ИИ и другие игроки по локальной сети.

Все модели, текстуры, звуки и музыка — **загруженные из интернета открытые ассеты** (Kenney, Poly Haven, Wikimedia Commons, Kevin MacLeod). Список и лицензии — в [THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md); обязательная атрибуция CC BY показывается в игре (Главное меню / Пауза → «Авторы и лицензии»).

## Быстрый старт

1. **Unity Hub → Add → Add project from disk** (Unity 6.6, проект создан под 6000.6.8f1).
2. При первом открытии редактор сам:
   - создаёт и назначает URP Asset (если конвейер не настроен);
   - создаёт сцену `Assets/CityBiz/Scenes/Galleria.unity` и открывает её.
   - Пакет `com.unity.inputsystem` подключён в `Packages/manifest.json`. Если Unity предложит включить новый бэкенд ввода — можно согласиться: `InputAdapter` работает и с Input System, и со старым Input Manager (выбирается автоматически через define `CITYBIZ_INPUT_SYSTEM`).
3. **Play** → «Одиночная игра». ТЦ строится из чертежа за доли секунды, игрок появляется у главного входа.

Меню **CityBiz** в редакторе:

| Пункт | Что делает |
|---|---|
| Открыть ТРЦ «Галерея» | Открывает (или создаёт) сцену |
| Настроить URP | Создаёт URP Asset вручную, если автонастройка не сработала |
| Запечь ТЦ (статика + Occlusion Culling) | Сохраняет ТЦ в сцену (меши/материалы — под-ассеты `Assets/CityBiz/Generated/MallAssets.asset`), помечает статику и считает Occlusion Culling. Рекомендуется перед сборкой билда |
| Удалить запечённый ТЦ | Возвращает режим построения во время игры |

### Мультиплеер по локальной сети

Главное меню → «Создать сервер и играть» (порт 7777 по умолчанию). Остальные игроки: «Подключиться» с IP хоста. Хост управляет скоростью времени (⏸ ×1 ×3 ×10 ×30). Другие игроки видны как персонажи с именем над головой.

## ТРЦ «Галерея»

- **Три этажа** вдоль 140-метровой галереи с атриумом под стеклянным фонарём (солнце и небо видны через крышу), мосты через атриум, стеклянные ограждения.
- **Две пары эскалаторов** (1→2 и 2→3 этаж) с движущимися ступенями и **панорамный лифт** на все этажи.
- **68 помещений**: магазины вдоль галерей (разной ширины и проходимости), **островные киоски** в атриуме, **6 точек фудкорта** на 3 этаже со столиками, **склады**, **якорный супермаркет** в западном торце, фасад кинотеатра, LED-экран, фонтан, деревья в кадках, скамейки, навигационные стенды.
- **Помещения**: витрина с автоматической дверью, вывеска, рольставни (опущены, когда точка и ТЦ закрыты), баннеры «СДАЁТСЯ / ПРОДАЁТСЯ / РЕМОНТ / ИЩЕМ СОТРУДНИКОВ», табличка с часами работы. Интерьеры под тип бизнеса из моделей Kenney и Poly Haven.

## Игровой цикл: развитие предприятия

| Улучшение | Что даёт в экономике | Что видно в помещении |
|---|---|---|
| Интерьер (1–5) | Качество, удовлетворённость, репутация | Покрытие пола, растения, ковры, мягкая мебель, люстры |
| Витрина и реклама (0–4) | Больше посетителей заходит именно к вам | Световая вывеска, промо-стойка, LED-экран в витрине, вертикальный баннер |
| Оборудование (1–5) | Больше клиентов в час, +1 место для персонала | Больше касс, стоек, кофемашин, длиннее прилавок |
| Ассортимент (1–5) | Выше средний чек, шире круг покупателей | Больше стеллажей и товара на полках |
| Охрана (0–3) | Защита от вредительства | Антикражные ворота, камеры, охранник у входа |

Улучшения доступны в карточке помещения и на вкладке «Мои предприятия» (Tab). Улучшение интерьера (2 ч) и оборудования (1 ч) ненадолго закрывает точку на ремонт.

## Прочие механики

| Механика | Как работает |
|---|---|
| Помещения | Аренда (ежедневно; 3 дня долга — выселение) или покупка. Свои помещения можно сдавать и продавать другим игрокам |
| Бизнесы | Кафе, ресторан, фастфуд, мороженое, одежда, электроника, игрушки, косметика, книги, ювелирный, супермаркет (якорь), склад (−30% к закупкам) |
| Сотрудники | Рынок труда с ролями, навыками и ставками; мотивация; нанятые стоят за стойками |
| Покупатели | Посещаемость ТЦ по часам (открыт 10:00–22:00), выходным и погоде делится между точками по цене, качеству, репутации и проходимости места |
| Вредительство | Фейковые отзывы, порча оборудования, отключение света, переманивание сотрудника, наводка проверки. Охрана снижает успех |
| Игроки | Аренда друг у друга, предложения о продаже, переводы, чат, видимые аватары |
| Конкуренты-ИИ | Громов (агрессивный), Ветрова (премиум), независимые арендаторы — действуют теми же командами |

## Живая атмосфера

- **Посетители** (персонажи Kenney с анимациями) гуляют по графу галерей между этажами через эскалаторы, разглядывают витрины, сидят на скамейках и за столиками фудкорта; утром ТЦ наполняется, к закрытию пустеет, ночью пуст.
- **Покупатели** приходят в работающие точки с частотой, пропорциональной реальному числу клиентов из экономики, заходят к полкам/кассам (у киосков и на фудкорте — к стойке) и выходят с пакетами.
- **Персонал** за стойками = нанятые сотрудники; охранник у входа при охране 3 уровня.
- **День и ночь** через стеклянный фонарь: солнечные пятна в атриуме, небо, вечером искусственный свет; после закрытия — дежурное освещение, рольставни опущены, вывески гаснут.
- **Погода**: облака приглушают солнце, дождь виден на стеклянной крыше и **слышен по крыше** (громче на 3 этаже), в грозу — вспышки молний.
- **Звуки** (только загруженные файлы): гомон ТЦ (зависит от числа посетителей), тихий фон, фудкорт и гул эскалаторов в 3D, фоновая музыка ТЦ, объявления, двери, кассы, шаги (камень в галерее, мягкий пол в магазинах), звуки интерфейса.

## Архитектура

```
Assets/CityBiz/
  Resources/        загруженные ассеты: Kenney/, PolyHaven/, Audio/{Ambience,Footsteps,Music,Sfx,UI}
  Runtime/Core/     CityBiz.Core — чистый C# без UnityEngine (noEngineReferences)
    Economy/        состояние, симуляция, правила, команды, улучшения, вредительство, ИИ
    Net/            протокол, дельта-репликация, сервер/клиент, Loopback и TCP
    Content/        MallContent — экономическое описание ТЦ (помещения, стартовые арендаторы)
  Runtime/Game/     CityBiz.Game — Unity-слой
    World/          MallBlueprint + MallRegistry + MallInstance, GalleriaBlueprint, MallBuilder, MallKit, Escalator, PedestrianGraph
    Shops/          StorefrontView (помещение, витрина, вывеска, рольставни, персонал), ShopInteriorBuilder (интерьеры по уровням)
    Assets/         AssetCatalog (загрузка моделей из Resources, нормализация, материалы URP), CharacterRig (анимации Kenney)
    Buildings/      автодвери, взаимодействие (IInteractable), стенды «Схема ТЦ», кнопки лифта
    Environment/    DayNightCycle, WeatherController, LightBudget, MallAudio + AudioLibrary
    AI/             PedestrianSystem — посетители и покупатели
    Player/         FirstPersonController, RemotePlayers, InputAdapter (Input System / Input Manager)
    Rendering/      MeshBuilder (+GeneratedMesh), MaterialLibrary, GPU-инстансинг, мост к URP, 3D-текст
    UI/             GameUI (IMGUI), Credits
  Editor/           автонастройка URP, сцена, запекание статики и Occlusion Culling
  Tests/EditMode/   тесты ядра (Unity Test Runner и dotnet test)
```

- **Сервер авторитетен.** Все действия — команды, которые сервер валидирует; одиночная игра идёт через тот же протокол (Loopback).
- **Ядро не зависит от движка** — запускается на выделенном .NET-сервере и покрыто тестами.
- **Экономика и геометрия совпадают**: размеры и позиции помещений берутся из `MallContent`, чертёж строит по ним витрины, граф пешеходов и схему этажей.

### Оптимизация

- **Отсечение**: архитектура собрана в крупные меши по этажам и участкам 36 м; интерьеры помещений активны только ближе 48 м и примерно на своём этаже (±9 м по высоте); запекание считает Occlusion Culling (стекло не считается окклюдером).
- **GPU Instancing**: столы и стулья фудкорта, скамейки, кадки, светильники, товары на полках — `Graphics.RenderMeshInstanced` пачками по ячейкам 48×48 м с отсечением по frustum и дистанции.
- **Свет**: `LightBudget` держит реальные точечные источники только у 12 ближайших светильников галерей (с приоритетом своего этажа) и у 6 ближайших магазинов; остальное — эмиссия. Солнце с тенями попадает внутрь только через фонарь.
- **NPC**: пул персонажей, скрытие дальних и находящихся на других этажах, тени только вблизи, анимация вдали обновляется каждые 2–4 кадра, не больше одного поиска пути покупателя за кадр.
- **Память**: сгенерированные меши принадлежат компоненту `GeneratedMesh` и уничтожаются при пересборке интерьеров и выходе из игры; материалы-ассеты запечённой сцены после Play Mode возвращаются к исходным значениям.
- **Коллайдеры**: только Box/Capsule; ограждения атриума, перегородки между эскалаторами, шахта лифта и стены не дают выйти в пустоту атриума.
- **Сеть**: дельта-репликация сущностей 4 Гц, позы игроков 10 Гц с квантованием; посетители не передаются (каждый клиент генерирует их по реплицированной статистике бизнеса).

### Как добавить новый ТЦ или крыло

1. **Ядро**: описать помещения и стартовых арендаторов — новый `MallDef` (по образцу `MallContent.CreateMall`) и добавить его в мир через `WorldDefinition.AddMall` (например, в `MallContent.CreateWorld` или собственном методе создания мира). Множители `RentMultiplier`, `Wealth`, `BaseVisitorsPerHour` задают отличие (премиальный ТЦ, аутлет…).
2. **Unity**: наследник `MallBlueprint` с `MallId` нового `MallDef`, `DisplayName`, `WorldOffset` (чтобы не пересекаться с другими ТЦ/крыльями) и методом `Build(MallKit kit, MallInstance inst)`: перекрытия (`kit.Slab`), стены, ограждения, эскалаторы (`kit.Escalator`), помещения (`StorefrontView.Create` для каждого `PropertyDef`), граф пешеходов, `LightAnchors`, `Map`, `ElevatorStops`, `PlayerSpawn`. Зарегистрировать: `MallRegistry.Register(new MyWingBlueprint())` (до старта сцены, например из `[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]`).
3. Симуляция, сеть, UI (схема этажей, лифт), посетители, свет, звук и запекание подхватят ТЦ без изменений существующего кода.

## Проверка

- Тесты ядра (экономика, улучшения, конкуренция, вредительство, выселение, сделки, детерминизм, репликация, игра по TCP):
  ```
  dotnet test tools/CoreTests
  ```
  В Unity те же тесты — **Window → General → Test Runner → EditMode**.
- Компиляция Unity-кода без редактора против управляемых сборок Unity 6.6 (нужна распакованная папка `Editor/Data`, путь — переменная `UNITY_EDITOR_DATA`, по умолчанию `/tmp/unity/Editor/Data`):
  ```
  dotnet build tools/UnityCompileCheck/Core.csproj
  dotnet build tools/UnityCompileCheck/Game.csproj
  dotnet build tools/UnityCompileCheck/Editor.csproj
  ```
  Эти проекты компилируют игровой слой по пути старого Input Manager. Путь Input System проверялся отдельной локальной сборкой против исходников пакета `com.unity.inputsystem` 1.20.1 (вне репозитория).

> **Честно о проверке.** Код компилируется без ошибок и предупреждений против настоящих сборок Unity 6000.6, тесты ядра проходят, а все пути `Resources.Load` указывают на существующие файлы. Однако **в Unity Editor проект не запускался** (нет лицензии в среде разработки): внешний вид, освещение, импорт FBX/анимаций, звук и ощущение управления не проверены вживую. При первом запуске стоит пройтись по ТЦ, проверить эскалаторы, лифт, схему этажей и запекание.
