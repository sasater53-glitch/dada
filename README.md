# CityBiz — стартовый район «Липовая улица» (Unity 6.6)

Мультиплеерный бизнес-симулятор в современном городе. Первый этап — **один небольшой, но полностью играбельный район** вместо большого пустого города: недвижимость, аренда, бизнесы, сотрудники, покупатели, конкуренция, вредительство и экономика работают уже сейчас.

## Быстрый старт

1. Откройте папку репозитория в **Unity Hub → Add → Add project from disk** (Unity 6.6, проект создан под 6000.6.8f1; другая патч-версия 6.6 тоже подойдёт).
2. При первом открытии редактор сам:
   - создаёт и назначает URP Asset (если в проекте нет конвейера);
   - создаёт сцену `Assets/CityBiz/Scenes/StarterDistrict.unity` и открывает её.
3. Нажмите **Play** → «Одиночная игра». Район генерируется за доли секунды.

Меню **CityBiz** в редакторе:

| Пункт | Что делает |
|---|---|
| Открыть стартовый район | Открывает (или создаёт) сцену района |
| Настроить URP | Создаёт URP Asset вручную, если автонастройка не сработала |
| Запечь район (статика + Occlusion Culling) | Сохраняет район в сцену как ассеты, помечает статику и рассчитывает Occlusion Culling (рекомендуется перед сборкой билда) |
| Удалить запечённый район | Возвращает режим генерации во время игры |

### Управление
WASD — ходьба · Shift — бег · Пробел — прыжок · мышь — камера · колесо — дистанция · V — вид от первого лица · **E — взаимодействие** · Tab — портфель · M — карта · Enter — чат · Esc — меню · F1 — справка · F3 — статистика производительности.

### Мультиплеер по локальной сети
Главное меню → «Создать сервер и играть» (порт 7777 по умолчанию). Остальные игроки: «Подключиться» с IP хоста. Хост управляет скоростью времени (⏸ ×1 ×3 ×10 ×30).

## Что есть в районе

- **Главная улица** с перекрёстком, разметкой, «зебрами», стоп-линиями, светофорами (с пешеходными секциями), бордюрами, люками, парковочными карманами.
- **12 проработанных зданий** пяти архитектурных стилей: кирпичный дом 1930-х с кафе, стеклянный бутик-хаус, классический дом с карнизами, пилястрами и рестораном, семиэтажный бизнес-центр «Липа», угловой дом, супермаркет за парковкой, панельный дом с двумя помещениями, павильон у остановки, два таунхауса, склад с рампой и подъёмными воротами.
- **Фасады с настоящими нишами окон** (откосы, рамы, подоконники, перемычки, сандрики, ставни), балконы с ограждениями, кондиционеры, водостоки, цоколи, парапеты, оборудование на крышах, двускатные крыши с трубами.
- **Витрины** с импостами и автоматическими раздвижными дверями, **вывески** с названием бизнеса (ночью подсвечиваются), маркизы, баннеры «СДАЁТСЯ/ПРОДАЁТСЯ», таблички с режимом работы, домовые номерные знаки.
- **Интерьеры под тип бизнеса**, которые перестраиваются при открытии/смене бизнеса и улучшаются с уровнем: кафе (стойка, кофемашина, витрина с выпечкой, столики), ресторан (бар с бутылками, раздача, столы со скатертями и свечами), магазин одежды (рейлы, стеллажи, манекены, примерочные, зеркало), супермаркет (кассы, ряды стеллажей с товаром, холодильники, овощной прилавок, тележки), склад (стеллажи с паллетами, погрузчик), пустое помещение (ремонт), лобби бизнес-центра с табло арендаторов.
- **Летние веранды** у кафе и ресторанов, **сквер** с фонтаном (частицы воды), клумбами, детской площадкой и скамейками, мощёная площадка с рекламным щитом, киоски «Цветы» и «Мороженое».
- **Остановки** с павильонами, лайтбоксами и табличками; **автобус** маршрута 14 останавливается на них.
- **Уличная мебель**: фонари, деревья трёх видов в приствольных решётках, скамейки, урны, столбики, паркоматы, гидранты, велопарковки, кашпо, живые изгороди, почтовый ящик, телефонная будка, дорожные знаки с названиями улиц.
- **Фоновая застройка** вдоль улиц и второй ряд домов закрывают горизонт — у района нет «края мира».

## Живая атмосфера

- **Прохожие** гуляют по графу тротуаров, ждут зелёный на переходах, разглядывают витрины, ждут автобус, сидят у фонтана, заходят в подъезды.
- **Покупатели** приходят в работающие магазины с частотой, пропорциональной реальному числу клиентов из экономики, заходят внутрь к стойкам и полкам, выходят — из магазинов одежды и супермаркета с пакетами.
- **Сотрудники** стоят за стойками в рабочие часы (их количество = нанятый персонал).
- **Машины** держат дистанцию, останавливаются на красный, тормозят перед игроком; плотность зависит от времени суток и погоды. Припаркованные машины вдоль улиц и на парковках.
- **Смена дня и ночи**: солнце и луна, процедурное небо, рассеянный свет, туман, фонари, фары, окна квартир и офисов загораются в разное время, вывески светятся.
- **Погода** (ясно, облачно, дождь, гроза, туман): капли дождя, мокрый блестящий асфальт, молнии и гром. Погода влияет на число прохожих и на спрос (в дождь чаще ходят в кафе).
- **Звуки улицы** (синтезируются, без ассетов): гул города, двигатели ближайших машин в 3D, гомон прохожих, птицы днём, сверчки ночью, дождь, гром, колокольчик дверей магазинов.

## Архитектура

```
Assets/CityBiz/
  Runtime/Core/   CityBiz.Core — чистый C# без UnityEngine (noEngineReferences)
    Economy/      состояние, симуляция, правила, команды, вредительство, ИИ
    Net/          протокол, дельта-репликация, сервер/клиент, Loopback и TCP-транспорты
    Content/      экономическое описание районов (стартовый район)
  Runtime/Game/   CityBiz.Game — Unity-слой
    World/        чертежи районов, реестр районов, построитель, граф пешеходов, пропсы
    Buildings/    фабрика зданий, интерьеры, PropertyView, двери, свет в окнах
    Rendering/    MeshBuilder, процедурные текстуры, библиотека материалов, GPU-инстансинг, мост к URP
    Environment/  день/ночь, погода, звук, бюджет источников света
    AI/           NPC, пешеходы, транспорт, светофоры
    Player/ UI/   игрок, ввод (Input System и старый Input Manager), интерфейс
  Editor/         автонастройка проекта, сцена, запекание статики и Occlusion Culling
  Tests/EditMode/ тесты ядра (Unity Test Runner и dotnet test)
```

- **Сервер авторитетен.** Все действия — команды (`Command`), которые сервер валидирует; id игрока берётся из соединения, а не из сообщения. Одиночная игра идёт через тот же протокол (Loopback), поэтому сетевой путь проверяется всегда.
- **Ядро не зависит от движка** — его можно запустить на выделенном сервере (.NET) и полностью покрыть тестами.
- **Детерминизм**: своя реализация xorshift128+, одинаковый seed → одинаковый мир.

### Оптимизация

- **LOD**: у каждого здания детальный LOD0 и упрощённый LOD1 с текстурой окон, отсечение на дальней дистанции.
- **Occlusion Culling**: меню «Запечь район» помечает статику (Occluder/Occludee) и рассчитывает данные; камера использует их автоматически. Интерьеры дополнительно отключаются дальше 45 м от камеры.
- **GPU Instancing**: деревья, фонари, скамейки, урны и прочая мебель рисуются через `Graphics.RenderMeshInstanced` пачками по ячейкам 48×48 м с отсечением по frustum и дистанции.
- **Минимум draw calls**: всё здание — один меш с подмешами, улицы — один меш, интерьер — один меш; общая библиотека материалов работает на SRP Batcher.
- **Коллайдеры**: только BoxCollider/CapsuleCollider, без MeshCollider.
- **Свет**: реальные источники только у 10 ближайших фонарей и по одному в активных интерьерах (без теней); остальное — эмиссия.
- **NPC**: пул объектов, общие меши и квантованная палитра материалов, тени только вблизи, анимация дальних NPC реже, скрытие дальше 170 м.
- **Сеть**: дельта-репликация на уровне сущностей с частотой 4 Гц (передаются только изменившиеся записи, varint-кодирование), позы игроков — 10 Гц с квантованием и радиусом интереса 250 м, косметические NPC не передаются вовсе (их генерирует каждый клиент по реплицированной статистике бизнеса).

### Как добавить новый район

1. В ядре: описать объекты недвижимости и стартовую расстановку — новый `DistrictDef` (по образцу `StarterDistrictContent`) и добавить его в `WorldDefinition`.
2. В Unity: наследник `DistrictBlueprint` с планировкой (дороги, здания с `LotKey`, пропсы, полосы, граф пешеходов) и `WorldOffset` для стыковки с соседними районами; регистрация через `DistrictRegistry.Register`.
3. Симуляция, сеть, UI, NPC, транспорт и запекание подхватят район без изменений в существующем коде. Экономические множители района (`RentMultiplier`, `TrafficMultiplier`, `Wealth`) дают разницу между, например, богатым районом и промзоной.

## Проверка

- Тесты ядра (экономика, конкуренция, вредительство, выселение, сделки, детерминизм, репликация через Loopback, игра по TCP):
  ```
  dotnet test tools/CoreTests
  ```
  В Unity те же тесты доступны в **Window → General → Test Runner → EditMode**.
- Проверка компиляции Unity-кода без редактора (нужна распакованная папка `Editor/Data` Unity 6.6):
  ```
  UNITY_EDITOR_DATA=/path/to/Unity/Editor/Data dotnet build tools/UnityCompileCheck/Editor.csproj
  ```
